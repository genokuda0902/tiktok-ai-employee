# Portrait media pipeline v2 — prototype, not publish-ready

Uses independent native 9:16 approved images and videos, per-scene motion, narration duration validation and caption timing sidecar. Outputs 1080x1920 MP4 and QA JSON. **Not tested with a real cleared asset set yet. Captions are not burned in; the output is NOT ready to post.** Human rights and editorial review remain mandatory. No source media, secrets or personal data should be committed.

Run: `python video_engine/portrait_v2/build.py --config /private/path/config.json` (requires Pillow, ffmpeg, ffprobe). Config keys: `output`, `narration`, `captions`, `assets` mapping IDs to metadata, `scenes` list of `{asset_id,seconds,motion}`. Each asset needs `path`, `type` (`image` or `video`), `source_type` (`self_shot`, `licensed`, `official_permission`, `ai_disclosed`), `rights_basis`, `rights_evidence`, `commercial_use:true`, `derivatives_allowed:true`, `privacy_review:"approved"`; AI assets also require `ai_disclosure`. These metadata are human assertions, not automatic licence verification. Scene motion: `static`, `zoom_in`, `zoom_out`, `pan_left`, `pan_right`. Captions sidecar is a JSON list of `{text,start,end}`. Narration duration must match scene total within 0.35 seconds.

Raspberry Pi 5 source checklist: (1) accurate product front/back closeups; (2) actual connected monitor/keyboard scene; (3) approved real PC screen capture with fictitious data; (4) electronics or programming use case. Acquire by self-shooting with written owner/performer permission and no identifiable/private screens, or obtaining explicit permission/licence covering commercial video, edits and distribution. A manufacturer image on a public product page is not automatically cleared. Do not use old AI composite as evidence of real hardware. Save evidence and media in access-controlled storage, not public GitHub.

AivisSpeech recovery: existing manual-only `.github/workflows/raspberry-pi5-voice.yml` downloads a model, starts Docker CPU engine at 10101, runs `src/gadget_voice.py`, and uploads WAV/timings. Do not trigger or modify this workflow without authorization. Confirm model-specific commercial terms and obtain a pronunciation-reviewed artifact. Engine licence alone does not clear a model.

Before release: implement verified subtitle burn-in, fix and test FFmpeg filter syntax and scene transitions, run PR #15 QA on a real render, listen to full narration and compare pronunciation, inspect all frames/phone safe zones, verify all licences, record human sign-off. No TikTok upload.
