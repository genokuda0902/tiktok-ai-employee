# cycle864 — real local-browser operation (review-only)

Compared with cycle863's static Python-calculation card, this cycle captures **actual local Chromium DOM interactions** using Playwright. The demonstration uses four **synthetic** task records. The browser checks three tasks, computes 75%, generates a report, and reorders the conclusion.

This repository PR includes the reusable 10-genre validation core and 13 offline unit tests. The **full Playwright capture script, source video, finished 1080×1920 H.264/AAC MP4, action log, 24 inherited Japanese subtitle beats, and technical QA evidence** are delivered in the chat's downloadable cycle864 ZIP. They are not published to this repository and are not produced by GitHub Actions.

Run CI-equivalent tests locally:

```bash
python -m unittest discover -s automation/cycle864 -p 'test_*.py' -v
```

The video inherits a previously generated Japanese narration track and existing slides. Audio bitstream identity is checked. **It is not a real AI SaaS or Excel operation**, and human review of Japanese pronunciation, semantic subtitle alignment, source rights, mobile playback, reference parity and employee approval is still required.
