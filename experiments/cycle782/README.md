# Cycle782 story-progress experiment

Requires local cycle781 MP4, Python 3 and FFmpeg. Run from this directory:

`python render.py --source /path/to/cycle781.mp4 --manifest manifest.json --output /tmp/cycle782.mp4 --qa /tmp/qa`

The manifest pins the input SHA256. Review-only output: source and audio rights, spoken Japanese text and publication approval remain unverified. No automatic posting or merge. This branch contains code only, not source media.
