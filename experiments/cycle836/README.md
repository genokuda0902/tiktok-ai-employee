# cycle836 photo-first layout

A no-cost, 1080×1920 reusable image-slide component for ten genres. It enlarges the photograph, adds dark contrast scrims, and reserves the bottom for separately timed Japanese ASS subtitles.

The full locally rendered MP4 is distributed as a separate human-review artifact, not committed to Git. This repository CI validates the shared layout only; it does **not** render or verify the MP4. Reuse of prior synthetic images and narration requires final rights and employee review. No merge, posting, or paid services.

Previous cycle835: inset photo/split hero. Current cycle836: edge-to-edge photo-first design, headline overlay, contrast scrims. 8 slide images, 24 prior ASS states, 25.833 s, H.264/AAC; local QA evidence is in the review package.
