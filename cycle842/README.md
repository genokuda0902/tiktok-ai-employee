# cycle842 — 写真領域だけの12フレーム・ディゾルブ（レビュー専用）

## 前回との差分
cycle841は24状態の1フレーズ字幕と日本語音声を復旧した一方、静止画入力のxfade時刻基準エラーで場面転換がハードカットに退行していた。

今回は8場面の長さ（89,81,79,87,86,89,77,103フレーム）を変えず、7か所の境界で12フレーム（0.4秒）ずつ、**写真領域のみ**をマスク付きでクロスディゾルブ。見出し、STEP表示、字幕カードは移動させず、24状態の日本語字幕を最後に描画。前回のAAC音声はストリームコピーで完全維持する。

## 技術
- 1080×1920、30fps、691フレーム、23.033秒
- フレーム数を明示したCFR短尺クリップを結合。問題があったループ画像のxfadeは使わない。
- 10ジャンルの共通エンジン。check_manifestは権利未承認、個人情報なし、投稿禁止を必須にする。
- CIはPython単体テストのみ。画像素材、完成MP4、音声はGitHubにアップロードしない。
- ローカルMP4は生成・全フレーム/音声復号を検証済み。13/13チェック成功。
